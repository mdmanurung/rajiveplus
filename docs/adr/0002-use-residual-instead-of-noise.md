# Use Full Component Vocabulary

The decomposition vocabulary will use full component names consistently in code and documentation: joint, individual, and residual. This is a deliberate breaking API cleanup. `get_block_matrix(type = "noise")`, generated documentation, examples, tests, public table/list labels such as `Indiv` and `Resid`, internal role names such as `$block_decomps` entries, and local variables/helper names should be replaced by individual/residual wording when they refer to decomposition components. Old public calls that request `type = "noise"` should fail with a targeted migration error directing users to `type = "residual"`, not silently alias or warn-and-continue. The word noise remains valid only where it means actual stochastic error or perturbation, such as simulation noise, Monte Carlo noise, or a discarded-spectrum noise-tail estimate.
